# 📋 Backlog do Produto - AlfaLog

**Cliente:** Secretaria de Desenvolvimento Econômico de São José dos Campos  
**Curso / Semestre:** 1º Semestre Logística (2026-1)  
**Tecnologias utilizadas:** VS Code, Gemini, Power BI, GitHub  
**Apresentação final:** 03/12/2026  

| Rank | Prioridade | User Story | Sprint |
| :---: | :---: | :--- | :---: |
| 1 | Alta | Como tomador de decisões de políticas públicas, eu quero extrair e filtrar os registros da base pública da RAIS referentes exclusivamente ao município de São José dos Campos utilizando VS CODE e EXCEL, para trabalhar apenas com os dados locais relevantes do projeto. | 1 |
| 2 | Alta | Como tomador de decisões de políticas públicas, eu quero tratar os dados de CNAE e categorizar as empresas nos grandes grupos do ecossistema (Aeroespacial, Automotivo, Químico, TI, Logística e Serviços Especializados), para permitir a análise segmentada do perfil produtivo. | 1 |
| 3 | Média | Como tomador de decisões de políticas públicas, eu quero criar e visionar o repositório público do projeto no GitHub, para garantir a rastreabilidade dos scripts de tratamento e organização da documentação técnica. | 1 |
| 4 | Alta | Como tomador de decisões de políticas públicas, eu quero visualizar um painel no Power BI com KPIs de total de empresas, volume de empregos e representatividade de cada setor, para compreender o peso econômico do ecossistema de SJC. | 2 |
| 5 | Média | Como tomador de decisões de políticas públicas, eu quero visualizar a distribuição geográfica das empresas e setores por bairros ou regiões de SJC em um mapa interativo, para identificar áreas de concentração industrial e tecnológica. | 2 |
| 6 | Média | Como tomador de decisões de políticas públicas, eu quero comparar indicadores de desempenho entre os setores aeroespacial, automotivo e de tecnologia, para avaliar o grau de inovação e densidade produtiva. | 2 |
| 7 | Média | Como tomador de decisões de políticas públicas, eu quero navegar por uma interface intuitiva com layout limpo e padronizado no Power BI, para extrair insights rápidos e acionáveis sem ambiguidades. | 3 |
| 8 | Média | Como tomador de decisões de políticas públicas, eu quero ler um relatório técnico completo descrevendo as fontes públicas, metodologia de limpeza, análises e conclusões, para validar o rigor acadêmico do trabalho. | 3 |
| 9 | Baixa | Como tomador de decisões de políticas públicas, eu quero acessar o repositório final totalmente organizado e documentado no GitHub, para conferir o projeto e replicar as análises se necessário. | 3 |
